# Security policy

This is pre-production research software. Do not expose the demo API directly to the public internet or supply confidential team information.

- No authentication, access control, or rate limiting is provided in v0.1.
- The local server binds to 127.0.0.1 by default.
- Report security concerns privately to the repository maintainer through GitHub (do not publish secrets in an issue).
- Rotate any credential accidentally committed to Git immediately; deleting a file does not remove credentials from Git history.
